## 🚀 Featured Projects

### 🖐 VisionInput — Gesture-Based VR Controller *(RGU Capstone)*
> A hands-free, gesture-based controller built for the James Hutton Institute's 360° immersive projection room in Aberdeen — replacing physical Xbox controllers with real-time hand tracking.

- **Stack:** Python 3.11 · Google MediaPipe · OpenCV · ViGEmBus (virtual controller emulation) · A-Frame
- **Features:** Split-hand control scheme (left = navigation, right = actions) · Two-layer gesture system (pinches + finger bends) · Inter-hand angle detection for ergonomic vertical-axis control · Debug overlay with live skeleton/joystick visualization · Session-based latency logging
- **Performance:** Median pipeline latency of **27.93ms** across 549 benchmarked trials
- **License:** MIT

## 🔧 Currently Building

### 🤖 Vector Mind
> Resurrecting an abandoned Anki Vector robot (Anki went bankrupt in 2019) with a fully local AI "brain" — no cloud dependency, no subscription, nothing phoning home.

- **Stack:** wire-pod (local voice pipeline) · Ollama + local LLM · Raspberry Pi 5 · Python
- **What it does:** Real-time conversation, persistent long-term memory, a taught-command curriculum, autonomous idle behavior, and safety reflexes (pickup/put-down/cliff detection) — all running end-to-end on a Pi 5 with zero external APIs
- **Why:** A hands-on deep dive into agentic loops, local inference constraints on ARM hardware, and giving a "dead" product a genuinely independent second life
